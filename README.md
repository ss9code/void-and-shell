# void-and-shell : 存在のトポロジー

**"中心が空っぽ（Void）であるからこそ、存在は外郭（Shell）を持つ"**

本リポジトリは、「存在とは何か」という根源的な問いに対し、幾何学、量子力学、そして自己相似性（フラクタル）の観点から考察した宇宙論的なフレームワークです。格子拘束の原理から始まり、運動による存在の定義、中心と外郭の相補性、そして最終的な宇宙の安定法則に至るまでの一連の理論を記述し、またそれをWebブラウザ上で体感できるインタラクティブ・アートとして視覚化しています。
